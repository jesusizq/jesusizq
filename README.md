## Featured Projects

### [agent-desk](https://github.com/jesusizq/agent-desk)
Mission control for AI coding agents. Running many sessions in parallel, each with its own swarm of sub-agents, means questions lost in terminal feeds and agents stuck without anyone noticing. agent-desk gathers everything that needs you into one inbox (questions, permission prompts, failures) and lets you answer from the browser or your phone: the answer reaches the exact session that asked, verbatim, and it carries on. It also shows what finished, with screenshots to compare side by side; what every sub-agent is doing, or why it is blocked; context and plan usage per session; worktrees eating the disk, with the commands to clean them. It can send `/compact` or Esc to a session's terminal, and opens that terminal in one click. Deterministic hooks, zero model tokens, nothing leaves the machine; provider-independent, with a Claude Code adapter today and room for Codex, Grok or any other agent CLI.

**Tech:** TypeScript, Node.js, provider adapters (Claude Code hooks), VS Code extension, tmux, Tailscale

### [Event Integrator](https://github.com/jesusizq/event-integrator)
Production-ready Python (Flask) microservice that aggregates, normalizes, and serves event data from external XML APIs. With async ingestion (Celery), Redis caching, and PostgreSQL storage. Designed for resilience: decouples reads from provider failures, ensures <50ms response times during heavy sync.

**Tech:** Python, Flask, Celery, Redis, PostgreSQL, Docker, Nginx

### [Polygon Triangulation](https://github.com/jesusizq/2DPolygonTriangulator)
High-performance C++ geometry processing pipeline for 2D polygon triangulation. Microservice backend with REST API, WebAssembly compilation for browser-native execution, and interactive WebGL visualization. Fully containerized and tested.

> **[Live demo](https://triangulator.jesusizquierdo.dev)**

**Tech:** C++, WebAssembly, WebGL, CMake, Docker
